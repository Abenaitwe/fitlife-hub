# FitLife Hub PHP Backend

These files provide a simple PHP/MySQL backend for the BIT1203 project requirement.

## Setup

1. Install a local server such as XAMPP or WAMP.
2. Create the database by importing `schema.sql` into MySQL.
3. Update database credentials in `config.php` if needed.
4. Place this project in the server web root.
5. Send forms to:
   - `backend/register.php`
   - `backend/login.php`
   - `backend/contact.php`
   - `backend/progress.php`

The GitHub Pages demo uses JavaScript and `localStorage` because GitHub Pages does not run PHP.
